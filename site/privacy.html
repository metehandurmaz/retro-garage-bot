Privacy Policy

Last updated: September 30, 2026

The Retro Garage upload tool is a private tool used only by the owner of the Retro Garage YouTube channel. It is not offered to the public and does not collect data from other people.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload videos to the Retro Garage channel and to read the channel's ID so it can confirm it is uploading to the right channel. It requests the scopes youtube.upload and youtube.

What is stored

The OAuth token is stored only on the channel owner's own server so the tool can upload without asking again. The tool keeps a local list of the stock clips it has already used. No personal data of viewers or other users is collected, sold, or shared.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time from Google Account permissions.
