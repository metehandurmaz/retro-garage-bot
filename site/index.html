Retro Garage

Retro Garage is a YouTube channel that publishes short videos of classic and vintage cars.

This site belongs to the channel's own upload tool. The tool uploads Shorts to the Retro Garage channel using the YouTube Data API. It only uses footage that is public domain or released under a license that allows reuse, and it credits the source in each video description.
